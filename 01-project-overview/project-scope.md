
# Mapping Operational Audits to NIST SP 800-53

## Project Overview

This project demonstrates how traditional business
operational audits can be evaluated through a
cybersecurity Governance, Risk, and Compliance (GRC)
perspective.

Using fictional business scenarios, I examine
operational procedures, identify potential risks,
evaluate existing controls, and map relevant
activities to NIST SP 800-53 Revision 5.

## Project Objectives

- Identify operational risks and control weaknesses.
- Evaluate existing business procedures.
- Map relevant procedures to NIST 800-53 controls.
- Identify appropriate audit evidence.
- Develop control testing procedures.
- Document findings and recommend remediation.

## Framework

NIST Special Publication 800-53 Revision 5.

## Project Deliverables

1. Financial Transaction Audit
2. Inventory Management Audit
3. Employee Access Audit
4. Food Safety Compliance Audit
5. Corrective Action Audit
6. NIST Control Mapping Matrix
7. Sample Control Assessments
8. Audit Findings and Recommendations

## Skills Demonstrated

- Risk Identification
- Internal Audit
- Control Mapping
- Control Testing
- Evidence Collection
- Compliance Documentation
- Gap Analysis
- Remediation Recommendations
