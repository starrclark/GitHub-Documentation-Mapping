# Audit Findings to NIST SP 800-53 Control Mapping

## Project Overview

This project demonstrates how fictional audit findings can be analyzed and mapped to applicable security controls within the NIST Special Publication 800-53 Revision 5 framework.

Using a fictional organization, Apex Retail Solutions, this project explores common operational and security weaknesses, identifies relevant NIST controls, and documents recommendations for addressing identified gaps.

## Project Objectives

- Analyze fictional audit findings.
- Identify security and operational control weaknesses.
- Research applicable NIST SP 800-53 controls.
- Explain why each control applies to an identified finding.
- Recommend corrective actions to reduce organizational risk.

## Organization

**Apex Retail Solutions**

A fictional retail organization operating multiple store locations and processing customer transactions, employee information, and business records.

## Project Scope

This project includes:
- Financial transaction review
- User access management
- Vulnerability management
- NIST control identification
- Control mapping and remediation recommendations

## Methodology

Each audit finding is evaluated using the following process:

1. Review the audit finding and supporting evidence.
2. Identify the underlying control weakness.
3. Research relevant NIST SP 800-53 controls.
4. Select the most applicable control.
5. Document the mapping justification.
6. Recommend corrective actions.

## Disclaimer

This is an independent educational portfolio project using fictional scenarios. It does not represent an actual organizational audit, official NIST assessment, or certification of compliance.
